# SimpleUnlocker Remastered 5.4 LIVE

Полнофункциональная диагностическая и восстановительная утилита Windows Forms для Windows 10/11 (.NET 8).

## Версия 5.4 — оптимизация без удаления функций

Сохранены все вкладки и инструменты версии 5.3, включая LIVE-мониторинг, процессы, автозагрузку, службы, планировщик, политики, Winlogon, драйверы, систему, диски, сеть, безопасность, восстановление, точки восстановления, резервные копии реестра, журнал событий, Debugger, Проводник и восстановление языков RU/EN.

Оптимизации:
- Адаптивный интервал LIVE: 4 секунды на системах с 2 ядрами или до 6 ГБ RAM; 2,5 секунды на более мощных системах.
- Дорогой опрос процессов выполняется только когда вкладка «Процессы» открыта, примерно раз в два LIVE-тиka; при активном WMI новые/завершённые процессы по-прежнему отслеживаются событиями.
- Первичное сканирование процессов отложено до открытия вкладки «Процессы».
- Список служб и дисков не сканируется при старте программы: пользователь запускает обновление по кнопке, что предотвращает задержки из-за медленных HDD, съёмных и сетевых дисков.
- Проводник не перечисляет файлы профиля при старте; загрузка начинается при выборе папки или явном открытии пути.
- Экземпляры ServiceController освобождаются после чтения.
- В Release включена оптимизация компилятора, отключены отладочные символы.

## Сборка

Загрузите проект в GitHub, откройте Actions и запустите **Build Windows EXE**. Артефакт: `SimpleUnlockerRemastered-5.4-LIVE-win-x64`.

## Важно

Проект не был скомпилирован и протестирован в Windows-среде в этой сессии. Перед использованием на основном ПК проверьте сборку и функции на тестовой системе. Для изменений системных настроек может потребоваться запуск от администратора. Языковая вкладка меняет предпочтения текущего пользователя; языковые пакеты Windows устанавливаются отдельно.
